## About This Repository

This repository documents my learning journey through an **Azure Database Administrator / DP-300** training course.

The focus is on understanding how to administer, secure, monitor, optimize, automate, and maintain relational databases using **Microsoft Azure SQL services and SQL Server**.

The repository contains my personal notes, T-SQL scripts, configuration examples, and hands-on exercises completed while studying the course.

> **Note:** This repository contains my own learning materials and implementations. It is not a reproduction of the course's copyrighted content.
